## 🧩 Solution Format

Every solution aims for clarity and efficiency, and includes complexity notes where relevant:

```cpp
// Time Complexity: O(n)
// Space Complexity: O(1)

class Solution {
public:
    int solve(vector<int>& arr) {
        // implementation
    }
};
```

The goal is to capture the **approach and reasoning**, not just a working answer.
